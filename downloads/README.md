# Downloads

This folder hosts installable builds for PauseScroll.

## pausescroll.apk

The Android APK for PauseScroll is **not yet available**.

Until then:

- **Android / desktop Chrome & Edge** — use the "Install app" button on the homepage
  (or the browser's native *Install / Add to Home screen* option). It installs the
  web app as a standalone, offline-capable app.
- **iPhone / iPad** — tap **Share**, then **Add to Home Screen**.

> The web version runs its timer inside PauseScroll. System-wide blocking of
> *other* apps requires the Android APK; that capability will ship with this file
> when it's ready. The homepage detects the missing file and shows a
> "coming soon" message instead of a broken download link.

Everything else on this site is a plain static web app — no download folder required.
